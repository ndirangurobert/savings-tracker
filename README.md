# SaveWise — Personal Savings Tracker

A responsive, browser-based savings tracker built with HTML, CSS and vanilla JavaScript. Currency is set to Kenyan Shillings (KES).

## Features
- Dashboard with current savings, monthly deposits, active goals and progress.
- Record deposits and withdrawals with dates, descriptions and notes.
- Prevent withdrawals above the recorded savings balance.
- Create multiple savings goals and track progress.
- Search and filter transaction history.
- Monthly savings chart and summary reports.
- Export transactions to CSV.
- Responsive desktop and mobile layout.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add your transactions and savings goals.

No build tools or package installation are required.

## Publish with GitHub Pages
1. Open repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Data and privacy
This starter version stores information in this browser's localStorage. Data is not synced to other devices and there are no user accounts, remote database or bank connections. Clearing browser site data can erase records, so export CSV backups regularly. Never enter bank passwords or sensitive account credentials.

## Project files
- `index.html` — page structure and dialogs.
- `styles.css` — responsive styling.
- `app.js` — transactions, goals, charts, reports and CSV export.
